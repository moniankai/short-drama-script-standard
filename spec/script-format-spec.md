## 一、核心原则：纯视听可演，不写无法拍出的心里话

1. **主体与动作清晰**：每一行动作描写都能直接转为分镜画面（AI 出图提示或实拍机位调度），明确写出谁在做、拿什么道具、面朝何处。
2. **杜绝网文心理小作文**：把「他心里盘算着」「脑海中闪过昨夜一幕」改成当前可见的动作、道具、对白或标准闪回场。
3. **配音气口自然**：单句台词简洁短促，重要情绪停顿可标注括号提示（公开市场样本中位句长 18.6 字含标点，带情绪提示台词占比约 44%）。

## 二、单集标准行结构

一集完整台本由「集头 + 若干标准场次」组成，常用六类行格式如下：

| 行型 | 格式示例 | 硬性要求 |
| --- | --- | --- |
| 集头 | `第1集` | 单独成行，集号连续 |
| 场头 | `【1-1 公司会议室·日·内】` | 必须含「集号-场号」、单一地点、单一时段（日/夜/晨/昏）、单一内外景（内/外）；闪回在末尾加 `（闪回）` |
| 人物行 | `人物：陈默、周宁` | 列出本场实到或开口人物，避免挂空名，也不要漏列开口角色 |
| 动作行 | `△陈默把合同拍在桌上，文件夹滑到周宁手边。` | `△` 开头；不以模糊「他/她」起句（同场两人以上必写姓名） |
| 独立特写 | `△【特写】合同签名栏盖着枚鲜红私章。` | 独立成行，只留关键物证/转折信息，单集不宜超过 2 条，避免连续扎堆 |
| 时间字幕 | `△【字幕：三日后】` | 只用于真实时间/空间跳变；手机微信、到账提示、系统弹窗一律改写为动作行 |
| 对白 / 独白 | `周宁（冷笑）：签了字，这单算谁的？` | `角色（情绪）：台词`；心声用 `角色 OS：`，画外音用 `角色 VO：`；齐声用 `甲（与乙齐声）：` |

## 三、常见问题自查清单一览（支持用 `tools/check_script_cli.py` 或在线体检页自动圈出）

### A. 结构硬伤
1. **缺少标准场头**：正文未识别出 `【集-场 地点·时段·内外】` 场头，分镜与场记无法拆场。
2. **复合拼盘场头**：同一场写成 `A地与B地`、`日至夜`、`内外`，应拆成独立两场。
3. **场号不连贯或集号错位**：第 1 集出现了 `2-1` 或场号跳跃，导致排期表错乱。
4. **相邻重复行 / 重复粘贴块**：连续两行或多行完全一致，常见于人工改稿或生成粘贴重复。
5. **人物行与发言不一致**：人物行列了未出场人名，或说话人未列入 `人物：` 行；多人发言不应写成 `甲、乙：`。
6. **假字幕**：把系统弹窗（叮）、银行到账、手机消息写成 `【字幕】`，应改为 `△手机屏幕亮起：……`。

### B. 影响画面与配音的小说腔 / 套话
7. **身体套话高频重复**：`指节`、`瞳孔骤缩/微震`、`嘴唇动了动/发颤`、`张了张嘴`、`冷得像冰`、`沉得像水`——改为直接可见的表情或道具动作。
8. **动作行里塞脑海闪回**：`脑海中闪过`、`想起刚才`——旧画面切闪回场，当下盘算改成对白或动作。
9. **无效否定尾句 / 先沉默紧接开口**：连续几个动作最后收在 `没说话`、`说不出话`、`没抬头`，尤其下一句又是同一角色立刻开口——直接删掉这一拍或写出实际替代动作。
10. **动作与括号情绪撞词**：动作行已写「冷笑」，下一行括号又标 `（冷笑）`，保留一处即可。
11. **多人在场代词起句**：场上两人以上，动作行用 `△他/她` 开头导致分镜认错主体——改为具体角色名。
12. **现代/非古风场景混入文言套词**：`须臾`、`顷刻`、`三息`、`且慢`、`莫要`、`旋即`、`三更`、`不多时` 等，改为自然口语。
13. **场尾跨空间动作与伪转场叙述**：当前场末尾出现 `△另一边，门口的……` 或 `镜头切到` 等，应另起标准新场。
